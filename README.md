## 📊 Report Pages

The Power BI file contains three report pages:

- **Slicer and Line Chart** — explore the monthly transaction amount trend.
- **Slicer and Column Chart** — compare transaction patterns using column-chart visuals.
- **Slicer and Matrix Visual** — inspect transaction information in a matrix-style view.

## 🎛️ Interactive Filters

The report includes slicers for fields such as:

- Bank name received
- Bank name sent
- City
- Device type
- Gender
- Transaction type
- Purpose
- Payment method
- Merchant name

Use the slicers to filter the report and explore different segments of the transaction data.

## 🧰 Tools Used

- **Microsoft Power BI** — report design, interactive visuals, and data exploration
- **Power Query / data model** — data preparation and modeling within the Power BI project

## 🚀 How to Use

1. Open the [live Power BI report](https://app.powerbi.com/groups/me/reports/3d4bc15e-0558-408b-9d5b-ccb842f25dfb/7ae526dc7b6fd0dffe7a?experience=power-bi).
2. If you have access, use the slicers to filter the report.
3. Select different report pages to explore trends, category comparisons, and the matrix view.
4. To inspect or edit the source project, open `UPI Transactions Data Analysis Project.pbix` in Microsoft Power BI Desktop.
